# Deploy from a phone

1. Upload this folder to a GitHub repository or a hosting service that can build Vite projects.
2. Build command: `npm run build`
3. Output directory: `dist`
4. Add a custom domain and HTTPS.
5. Keep the fee wallet as a public address only.

For production, replace the public RPC URL with a dedicated Solana RPC endpoint. Then complete and audit the bonding-curve/AMM integration before advertising Buy/Sell as an in-site market.
